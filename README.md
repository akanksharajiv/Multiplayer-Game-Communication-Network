# Multiplayer-Game-Communication-Network
An SDN-based multiplayer game communication prototype built with Python UDP sockets, Mininet, Open vSwitch and Ryu (OpenFlow 1.3). Simulates three networked hosts, exchanges game-state updates, logs RTT and variation to CSV, prioritises UDP port 5000 via QoS queues, and tests delay, packet loss and congestion with an automated launcher.
